# TermuGram

Инструмент для работы с Telegram прямо в Termux (Android). Вход в **личный аккаунт**
(телефон + код из Telegram), интерактивный установщик с выбором языка и темы,
главное меню с полезными действиями.

Автор: **Nyvella** · Версия: 0.7.0

---

## Возможности

- **Установщик** с реальным входом через [Telethon](https://github.com/LonamiWebs/Telethon):
  номер телефона → код из Telegram → двухфакторка (если включена)
- **3 языка**: русский, english, українська
- **4 темы оформления**: Dark, Neon, Light, Minimal (с предпросмотром)
- **Главное меню**:
  - инфо об аккаунте (имя, username, телефон, ID)
  - мои диалоги (первые 15) + последние сообщения выбранного
  - **скачивание медиа** из диалога: фото, видео, голосовые, аудио, стикеры,
    файлы — по одному или всё сразу (последние 20 медиа из 200 последних
    сообщений), сохраняются в `~/TermuGramDownloads/<диалог>/`
  - отправка сообщения: себе, из списка диалогов или по username/телефону
  - **обратная связь**: сообщение разработчику прямо из меню — категория
    (баг / улучшение / другое), шаблон «как писать», авто-инфо о версии и устройстве
  - **режим бота**: подключение по токену от @BotFather — инфо о боте,
    отправка сообщений от его имени, смена токена
- **Автопроверка обновлений**: при старте меню TermuGram спрашивает GitHub,
  вышла ли новая версия, и если да — показывает уведомление с версиями и
  командой обновления; версия видна прямо в заголовке меню
- Понятные сообщения об ошибках (без трейсбеков)
- Сессия и настройки хранятся локально, права 600

## Требования

- Termux (Android) — больше ничего вручную ставить не нужно:
  `install.sh` сам проверит окружение и доустановит всё необходимое
- API ID и API hash — берутся на [my.telegram.org](https://my.telegram.org):
  вход по номеру телефона → **API development tools** → создать приложение

## Установка (одной командой)

```bash
pkg install git -y
git clone https://github.com/DEXTERITY-maker/TermuGram.git
cd TermuGram
bash install.sh
```

Установщик **сам проверяет окружение Termux и чинит его** — никаких ручных
шагов и загадочных ошибок:

- **python3** — если не установлен или слишком старый, установит автоматически
  (`pkg install python`)
- **pip** — настроит, если вдруг отсутствует
- **telethon** (движок Telegram) — если не установлен или устарел, установит
  или обновит через pip
- **git** — доустановит (рекомендуется для обновлений)

Дальше копирует файлы в `~/.terminugram`, создаёт команду `TermuGram`
в `~/.local/bin` и печатает понятный итог. Если `~/.local/bin` не в PATH —
install.sh подскажет, что добавить в `~/.bashrc`.

## Использование

```bash
TermuGram              # главное меню (если настроен) или установка
TermuGram --setup      # заново пройти установку/вход
TermuGram --menu       # главное меню
TermuGram --demo       # демо интерфейса установщика (без входа)
TermuGram --update     # обновить до последней версии (git pull + install.sh)
TermuGram --version    # версия
TermuGram --help       # справка
```

## Обновление

Если вышла новая версия, главное меню само об этом сообщит при запуске.
Обновление — одной командой:

```bash
TermuGram --update
```

Она подтягивает изменения из GitHub и заново копирует файлы. Вручную то же
самое: `cd TermuGram && git pull && bash install.sh`.

## Где что хранится

| Путь | Что это |
|---|---|
| `~/.terminugram/` | рабочие файлы (копия программы) |
| `~/.terminugram/config.json` | настройки: язык, тема, телефон, API-ключи (права 600) |
| `~/.terminugram/tgtool_session.session` | файл авторизации Telethon (права 600) |
| `~/TermuGramDownloads/<диалог>/` | скачанные медиа (папка создаётся автоматически) |
| `~/.local/bin/TermuGram` | команда запуска |

`config.json` и `*.session` **не попадают в git** — это ваши приватные данные.
Не удаляйте их, если не хотите входить заново.

## Предупреждение

Работа с личным аккаунтом через API — серая зона. Telegram может ограничить
аккаунт за чрезмерную автоматизацию (флуд, массовые действия). Используйте
инструмент аккуратно и с низкой частотой запросов.
